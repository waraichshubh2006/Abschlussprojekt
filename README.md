# Dies ist mein Abschlussprojekt, das ich im Rahmen meines FITA-Kurses an der ReDi School of Digital Integration erstellt habe. Es handelt sich um ein Fachsprachquiz, das mit Python programmiert wurde. Man kann damit seine grundlegenden IT-Kenntnisse testen. Der Nutzer gibt einfach seine Antwort ein, und der Code gibt automatisch an, ob sie richtig oder falsch ist. Am Ende des Quiz wird die Gesamtpunktzahl angezeigt.
